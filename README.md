# Subsurface Lab
Subsurface Lab is a specialized Vertical Electrical Sounding (VES) web application designed for processing, modeling, and interpreting geophysical field data. It features robust 1D inversion modeling tools and automated report exporting functionalities to streamline subsurface analysis.
Features:
* VED data procession
* 1D inversion
* 3D pseudo-section

Visit the [website](https://subsurfacelab.muhammadabubakar.com.ng) for more info.
